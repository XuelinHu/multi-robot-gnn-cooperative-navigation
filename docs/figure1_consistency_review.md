## 下一版应采用的核心公式

令 `s=[W,H]`，`n_obs` 为最近障碍物指向机器人的单位方向，`d_obs` 为相应距离：

```text
x_i = [(g_i-p_i)/s, v_i/v_max, n_obs,i, clip(d_obs,i/4,0,1), 1] ∈ R^8
r_ij = p_i-p_j, Δv_ij = v_i-v_j
c_ij = -Δv_ij · r_ij/max(||r_ij||, 1e-6)
e_ij = [r_ij/s, Δv_ij/v_max, c_ij/v_max] ∈ R^5
A_ij = 1{0 < ||r_ij|| ≤ R}
h_i^0 = ReLU(W_enc x_i + b_enc)
d_i = max(1, Σ_j A_ij)
q_i^l = Σ_j A_ij h_j^l/d_i + Linear_edge(Σ_j A_ij e_ij/d_i)
m_i^l = ReLU(Linear_message,l(q_i^l))
h_i^(l+1) = ReLU(Linear_update,l([h_i^l || m_i^l]))
u_raw,i = v_max · MLP_head(h_i^3)
u_exec = norm_clip(optional_pairwise_filter(u_raw))
```

边编码器在三层间共享，消息层与更新层各层参数不同；所有机器人共享对应层的参数。非边位置的边特征由邻接掩码置零。

## 顺带发现的正文与实现差异（待最终调整）

1. 方法部分写 `v_max tanh(f(h_i))`，代码动作头没有 tanh：评估器乘1.4，环境再按向量范数限速。逐分量 tanh 本身也不能保证二维速度的欧氏范数不超过最大速度。
2. 正文带边消息公式将节点与边各自变换后求和；当前实现先聚合、叠加边编码，再统一经过带 ReLU 的消息层，二者并非一般等价。
3. 正文进度损失写世界坐标距离，训练代码使用按 `[16,12]` 归一化后的目标位移；平滑项比较预测动作与输入中的当前归一化速度，而不是直接读取前一时刻策略输出。最终公式应明确单位与归一化。
4. 训练器三项辅助损失权重默认均为0，是否全部联合启用需要逐个核对论文所用检查点的训练参数；“代码支持四项损失”不等于所有实验都启用四项。当前核验未认定所有检查点使用相同权重。
